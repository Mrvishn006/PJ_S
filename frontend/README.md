# VALUATE.AI — Frontend Dashboard

High-density financial terminal / real estate analytics web application built with **React**, **TypeScript**, and **Vite**.

## Features

- **Provenance Engine Header**: VALUATE.AI branding, JAD Dataset (2K CSV) source badge, 92.4% accuracy badge.
- **Top Navigation**:
  - `PREDICT PRICE` (Two-column layout, interactive parameters, calculated valuation, feature importance, natural language explanation)
  - `MYSQL ANALYTICS` (Aggregations, location breakdown, bedroom/age curves, interactive SQL console)
  - `PIPELINE METRICS` (Residual diagnostics, R², MAE, RMSE, Decision Tree specifications)
  - `PYTHON BLUEPRINTS` (11-stage architectural code viewer with copy capability)
- **Fintech Terminal Design System**: Dark navy cards, thin borders, green/teal highlights, monospace metrics, Indian currency format (`₹4,50,30,710`, `₹30,020/sq ft`).

## Setup & Running

```bash
cd frontend
npm install
npm run dev
```

App runs on `http://127.0.0.1:5173`.
